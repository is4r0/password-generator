## ✨ Features

* 🔐 **Random Password Generation**: Generate a new 12-character password with a mix of character types.
* 🔡 **Uppercase & Lowercase Letters**: Includes both uppercase and lowercase alphabetic characters.
* 🔢 **Numbers Included**: Adds numeric characters to increase password variety.
* 🔣 **Special Characters**: Includes symbols to create more complex passwords.
* ✅ **Character Requirements**: Every generated password contains at least one lowercase letter, one uppercase letter, one digit, and one special character.
* ⚡ **Lightweight & Simple**: Uses Python's built-in libraries without requiring external dependencies.
* 💻 **Command-Line Interface**: Generate a password directly from your terminal.

## 🚀 Quick Start

Follow these steps to run the program locally.

### Prerequisites

* **Python 3** or higher
* A terminal or command prompt
* Git (optional)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/is4r0/password-generator.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd password-generator
   ```

3. **Run the program**

   ```bash
   python password-generator.py
   ```

   If your system uses the `python3` command, run:

   ```bash
   python3 password-generator.py
   ```

4. **View your generated password**

   The program will print a randomly generated password in your terminal.
